SimplifyFile은 Windows PC에 쌓인 사진, 움짤, 동영상 중 중복에 가까운 파일을 빠르게 찾아 정리하기 위한 로컬 미디어 정리 도구입니다.

폴더를 선택하면 전체 파일 수, 미디어 파일 수, 확장자별 분포를 먼저 보여주고, 분석을 시작하면 이미지 해시와 영상 프레임 샘플링을 이용해 관련 파일을 그룹화합니다. 사용자는 썸네일과 함께 보기 화면에서 실제 파일을 확인한 뒤 정리 후보를 선택할 수 있습니다.

선택한 파일은 원하는 폴더로 이동하거나 휴지통으로 보낼 수 있으며, 필요할 경우 영구 삭제도 가능합니다. 모든 분석은 사용자 PC 안에서 이루어지며, GitHub Release에서 Windows 실행 파일을 내려받아 사용할 수 있습니다.
