WinPic 0.1.1 패치노트입니다.

이번 업데이트는 WinPic의 내부 구조를 대대적으로 정리한 안정화 업데이트입니다.  
특히 미디어 파일이 많거나 외장 드라이브를 사용하는 환경에서도 더 빠르고 예측 가능하게 동작하도록 인덱싱, 동기화, 파일 이동 흐름을 개선했습니다.

## 주요 변경사항

### 인덱싱 및 동기화 구조 개선

WinPic이 매번 전체 폴더를 다시 훑지 않도록 인덱싱 구조를 개선했습니다.

저장된 인덱스를 먼저 표시하고, 이후 변경된 파일만 반영하는 방향으로 구조를 정리했습니다. 폴더 변경 감지, 증분 갱신, 동기화 상태 표시 흐름도 함께 개선해 대량 미디어 환경에서의 반응성을 높였습니다.

### 파일 이동 알림 센터 추가

파일 이동 작업을 더 명확하게 확인할 수 있도록 알림 센터를 추가했습니다.

이동 작업의 진행 상태, 성공 개수, 실패 개수, 실패 사유를 확인할 수 있으며, 완료된 알림은 개별적으로 정리할 수 있습니다. 알림창은 접기와 다시 열기를 지원하며, 추후 동기화 완료 같은 다른 알림도 확장할 수 있는 구조로 변경했습니다.

### 앨범 이동 방식 개선

앨범 이동 시 기존 앨범에서 선택하거나 디스크의 폴더를 직접 탐색해 이동할 수 있도록 개선했습니다.

앨범 선택과 폴더 선택 UI를 통일했고, 카드 선택 후 하단 이동 버튼으로 확정하는 방식으로 변경해 실수 이동 가능성을 줄였습니다. 폴더 선택 중 새 폴더를 생성하는 기능도 추가했습니다.

### 외장 드라이브 상태 표시 개선

외장 드라이브가 연결되어 있지 않은 경우 `미연결` 상태로 표시되도록 개선했습니다.

또한 같은 드라이브 문자라도 실제 물리 드라이브가 다른 경우를 구분할 수 있도록 볼륨 식별 정보를 활용하는 구조를 추가했습니다.

### 폴더 탭 갱신 문제 수정

동기화 직후 폴더 탭의 사진·영상 개수나 하위 폴더 상태가 늦게 반영되던 문제를 수정했습니다.

이제 동기화 완료 후 폴더 개수 캐시를 다시 계산하고, 하위 폴더 정보도 최신 상태로 갱신됩니다.

### 자동 릴리즈 워크플로 추가

메인 브랜치에 코드가 반영되면 GitHub Actions가 자동으로 빌드, 테스트, 설치 프로그램 생성을 진행하도록 설정했습니다.

릴리즈에는 프로그램 추가/제거에 등록되는 설치 프로그램과 압축 파일, SHA256 체크섬이 함께 등록됩니다.

## 기타 개선

- 사진 탭 스크롤 중 깜빡임 완화
- 알림창 스크롤 및 여백 개선
- 폴더 선택창의 스크롤 전파 문제 수정
- 앱 중복 실행 방지
- 앱 종료 처리 안정화
- 파일 이동 후 중복 새로고침 문제 수정
